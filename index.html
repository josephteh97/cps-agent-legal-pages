CPS Agent Orchestrator

A desktop tool that uses local AI to generate short marketing videos and post them to your own TikTok account.

What it is

CPS Agent Orchestrator is a personal software project built and run by a solo developer. It is a desktop application (C# / .NET 8, Windows) that runs entirely on the operator's own machine. It is not a hosted service, has no public sign-up, and has no users other than its developer.

How it works

  • Locally-hosted AI models (Ollama, LM Studio, or llama.cpp) select affiliate products and draft short-video scripts. No cloud model APIs are used.
  • A local rendering step turns a script into a finished video: Windows text-to-speech for narration, composited with FFmpeg into a 1080×1920 H.264/AAC MP4.
  • The operator reviews the result in a local dashboard and may then choose to publish it to their own connected TikTok account.

TikTok integration

  • Login Kit — the operator connects their own TikTok account through TikTok's standard OAuth 2.0 authorization flow (with PKCE). Access and refresh tokens are stored only on the operator's local machine.
  • Content Posting API — a reviewed video is uploaded and posted to that same account.

Every post is triggered manually by the operator from the dashboard. Nothing is scheduled, queued, or published automatically, and posts are made at private (SELF_ONLY) visibility.

Data handling

The application does not collect, store, or share data belonging to any third party. Generated scripts and video files stay on the operator's own machine. No analytics, tracking, or advertising services are used. The only external service contacted is TikTok's own API, and only to perform a publishing action the operator has explicitly requested.
