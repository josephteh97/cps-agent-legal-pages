Privacy Policy

Last updated: 2026-08-23

CPS Agent Orchestrator is a personal, solo-developer software project, run locally by its developer. It is not a public service and does not have external users or accounts.

Data handled by the application:

  • TikTok OAuth access and refresh tokens, obtained only for the developer's own connected TikTok account, used solely to publish video content to that account via TikTok's Content Posting API.
  • Locally generated content (scripts, video files) produced by the application, stored only on the developer's own machine.

No data is transmitted to any third party other than TikTok's own API, as required to perform the publishing action the developer explicitly requests. No analytics, tracking, or advertising services are used.

For questions, contact the developer via the GitHub repository associated with this project.
